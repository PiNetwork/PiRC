## Overview

**OpenPay OpenUSD (OUSD)** is a USD-pegged utility stable token designed for payments, lending, staking, savings, merchant transactions, and governance within the OpenPay ecosystem.

Developed in alignment with the **Pi Network** ecosystem and supported by **MrWain Foundation**, OUSD aims to provide a stable digital currency with real-world utility.

**Peg Model:** 1 OUSD = 1 USD (targeted stability model)
**Type:** Utility Stable Token

---

## Utility Functions

OUSD is built to function as:

* 💸 Digital payment currency
* 🏪 Merchant settlement token
* 🏦 Lending & savings asset
* 🔄 Swap-compatible stablecoin
* 🗳 Governance participation token
* 🔒 Staking utility token
